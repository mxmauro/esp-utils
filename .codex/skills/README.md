# Repository Skills

These repository-local skills capture recurring `esp-utils` maintenance workflows for future Codex runs.

- `esp-utils-component-maintainer`
  - Use for public API, component layout, packaging, and test-sync work.
- `esp-utils-storage-concurrency`
  - Use for NVS, mutex, task lifetime, rundown protection, and run-once changes.
- `esp-utils-lightstd-and-buffer`
  - Use for lightweight containers, allocator, growable buffer, convert, and hash work.

All of them assume the repository rules in `AGENTS.md` and the current ESP-IDF component structure.
